# ATELIER NOIR

Магазин одежды на React / Vite / TypeScript / SCSS Modules и Django / SQLite. Реализация находится в `frontend/` и `backend/`. Корневые `index.html`, `index-2.html` и `index-3.html` сохранены как исходные макеты. Рабочая ветка — `master`.

## Обычный запуск

Локальная среда на текущем компьютере подготовлена: зависимости установлены, миграции применены, SQLite заполнена, изображения загружены.

В первом терминале, из `backend`:

```powershell
poetry run python manage.py runserver
```

Во втором терминале, из `frontend`:

```powershell
npm run dev
```

- Витрина: http://127.0.0.1:5173
- Django Admin: http://127.0.0.1:8000/admin/
- Данные локального администратора: `backend/.local/admin.txt`. Пароль случайный, файл исключён из Git. Покупательских аккаунтов нет.

Дополнительные серверы, Docker, Redis и фоновые очереди не требуются. Vite передаёт `/api` и `/media` в Django. При занятом порте укажите свободный явно через `npm run dev -- --port <порт>` и настройте CSRF origins.

## Что работает

- Каталог: поиск, категории, размеры, цвета, цена, новинки, сортировка и загрузка следующих товаров.
- Прямые ссылки на товары и быстрый просмотр; варианты с реальными остатками, выбор количества, корзина и промокоды.
- Гостевое оформление: контакты, ПВЗ или курьер СДЭК, серверный расчёт, резерв и защита повторной отправки.
- Страница заказа по секретной ссылке, переход к ЮKassa, проверка статуса сервером и обработчик webhook.
- Email покупателю и магазину, Telegram администратору: события оформления и оплаты. HTML + текстовая версия, защищённый предпросмотр и повторная обработка ошибок в админке.
- Русская Django Admin: каталог и фото, варианты/остатки, заказы, промокоды, контент, контакты, подключения и журнал.
- Проверяемый импорт Excel / CSV, встроенные фото Excel или фотографии из ZIP, настраиваемые колонки. Экспорт Excel с фото и CSV.
- Skeleton для текста, карточек, страниц и изображений, индикатор сетевых загрузок, состояния ошибок, клавиатурная навигация и reduced motion.
- Предрендеринг 22 публичных страниц при сборке: основной HTML, метаданные, canonical, Open Graph, sitemap и 404. Контент берётся из Django, а не из отдельного ручного каталога frontend.

## Локальные данные

16 товаров и 142 варианта исходного макета, локальные WebP-фотографии, страницы доставки/документов и промокод `FORM10` (10%). Первичное количество — 8 шт. каждого варианта. Проверочный заказ из браузерного теста может быть виден в админке; это локальная покупка без реального платежа.

Наполнение не перезаписывает существующие товары и настройки:

```powershell
poetry run python manage.py seed_store
```

Фото исходного макета: Unsplash. Для коммерческого запуска проверьте права на конкретные фотографии и замените их материалами бренда. Контакты `.example` и тексты документов — начальное наполнение; внесите данные продавца и утверждённые документы через админку.

## Интеграции

По умолчанию включён **локальный тестовый режим** в настройках магазина. Он имитирует доставку, оплату и отправки, не обращаясь к внешним сервисам. В админке видны режим и журнал; на витрине нет технических плашек. Страница проверки оплаты прямо сообщает об отсутствии списания.

Подключения подготовлены, но реальные операции не проверялись без реквизитов. Настройка и границы реализации: [docs/integrations.md](docs/integrations.md). Импорт: [docs/import.md](docs/import.md).

## Сборка и проверки

Из `frontend`:

```powershell
npm run typecheck
npm run build
```

Сборка сама экспортирует публичный контент через подготовленное Poetry-окружение backend. Запущенный Django для этого не нужен. После изменения каталога, страниц или публичного адреса перед размещением сайта повторите сборку.

Из `backend`:

```powershell
poetry run python manage.py check
poetry run python manage.py makemigrations --check --dry-run
poetry run python manage.py test orders catalog
```

## Первичная установка на другом компьютере

Нужны Python 3.12+, Poetry и Node.js 22.12+ либо 24+. Один раз:

```powershell
cd backend
poetry install
poetry run python manage.py migrate
poetry run python manage.py seed_store
cd ../frontend
npm ci
```

Для первого наполнения нужен доступ к Unsplash. База, медиа, ключи и пароли исключены из Git. Резервные копии базы и ключа шифрования храните отдельно от публичных файлов.

## Целевая структура

- `frontend/`: React, Vite, TypeScript strict, SCSS Modules; общие токены и глобальные reset/font rules отдельно. Разделение на оболочку, каталог, карточку вещи, корзину, оформление и общие элементы управления.
- `backend/`: Django + Poetry + SQLite, домены каталога, заказов, контента и интеграций. Models, admin, API/валидация и сервисы разделены по ответственности.
- Django — источник товаров, вариантов, цен, остатков, промокодов, заказов и редактируемого контента. LocalStorage допустим для корзины/предпочтений, но не как замена серверному каталогу.
- Vite proxy связывает `/api`, `/media` и при необходимости `/admin` с Django. Обычный запуск требует только двух процессов из ТЗ.

## Данные, безопасность и проверки

- Сервер рассчитывает цену и итог заказа, проверяет доступность вариантов и промокода. Критические изменения выполняются транзакционно.
- Секреты не входят в Git и ответы публичного API; секреты интеграций шифруются проверенной библиотекой, ключ находится отдельно.
- CSRF, серверная валидация, права сотрудников, ограничение чувствительных запросов и безопасная загрузка изображений.
- Локальные адаптеры интеграций не отправляют реальные уведомления и платежи; production не допускает локальный режим.
- Наполнение базы идемпотентно и не затирает пользовательские данные. Изображения для обязательного контента доступны локально.
- Проверки: typecheck, production build, Django checks, миграции, API и основные покупательские сценарии; критичная логика заказов и прав покрывается содержательными тестами.
